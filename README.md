# Tienda Ecommerce

Este es un proyecto de una tienda de comercio electrónico (E-commerce) desarrollado con HTML y CSS.

## Estructura del Proyecto

El proyecto contiene las siguientes secciones principales:

*   **Páginas para clientes:**
    *   `carrito.html`: Carrito de compras.
    *   `contacto.html`: Página de contacto.
    *   `index.html`: Página de inicio.
    *   `login.html`: Página de inicio de sesion.
    *   `registro.html`: Página de registro de usuario.
    *   `nosotros.html`: Página de información sobre la empresa.
    *   `productos.html`: Página de productos de la tienda.
*   **Panel de Administración (`/admin/`):**
    *   `home.html`: Panel principal del administrador.
    *   `productosadmin.html`: Gestión de productos.
    *   `usuarios.html`: Gestión de usuarios.
*   **Estilos (`/css/`):**
    *   Archivos CSS para los estilos de la tienda (`style.css`, `input.css`, `output.css`).
*   **Imágenes (`/img/`):**
    *   Fondos para las páginas de inicio de sesión y registro.

## Requisitos Previos

*   Un navegador web moderno.
*   (Opcional) Una extensión como Live Server en VS Code para facilitar el desarrollo local (el proyecto está configurado para usar el puerto 5501).

## Cómo ejecutar

Simplemente abre los archivos `.html` en tu navegador web. Si usas VS Code, puedes iniciar el proyecto usando la extensión Live Server.
